Satisfy the requirements with the fewest independent decisions.

A CLI and Nix flake library for managing your home directory, repositories, packages, and NixOS configurations. Shared conventions derive builds and checks from your files.

Install on NixOS

In flake.nix, use mkFlake to discover packages and hosts. Keep your existing module inputs: 

{
  inputs = {
    afairesi.url = "github:afairesi/afairesi";
    preservation.url = "github:nix-community/preservation";
  };
  outputs =
    inputs:
    inputs.afairesi.lib.mkFlake {
      inherit inputs;
    };
}

Add the CLI to my-host/configuration.nix, keeping your hardware imports, platform, and persistence settings. inputs is passed automatically; nixpkgs defaults to afairesi's input: 

{ inputs, pkgs, ... }:
{
  nix.settings.experimental-features = [ "nix-command" "flakes" ];
  environment.systemPackages = [
    inputs.afairesi.packages.${pkgs.stdenv.hostPlatform.system}.afairesi
  ];
}

From the flake directory, stage new files so Nix can see them, then apply:

git add flake.nix my-host/
sudo nixos-rebuild switch --flake .#my-host

With impermanence or preservation, persist the whole home directory, including Git metadata and checkouts, using a persistent filesystem or bind mount. Managed files and repository paths must not be symlinks.

Other systems: home and repo

With Nix, afairesi home and afairesi repo also work without NixOS. Enable flakes in ~/.config/nix/nix.conf: 

experimental-features = nix-command flakes

Run without installing:

nix run github:afairesi/afairesi -- repo --help

Or install for your user (Nix 2.30 or newer):

nix profile add github:afairesi/afairesi
