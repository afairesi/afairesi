afairesi

A computing environment designed to minimize independent decisions.

Source Paper MIT License

Afairesi applies one principle across your system, persistent state, home directory, repositories, packages, and tests: satisfy the requirements with the fewest independent decisions.

NixOS defines the system, Preservation retains declared state, and Git records source and repository revisions. Afairesi derives checkout locations from remotes, package names from directories, and builds, checks, and development environments from tracked sources and dependencies.

Git determines source membership. Select new files with git add -- PATH; use -f when deliberately tracking an ignored file. Afairesi stages the files it creates. The default.nix constructor selects the package type; supporting files can live anywhere.

afairesi repo fix repairs and stages structure. nix fmt formats tracked sources by file type, removes ordinary comments, and sorts Nix bindings. nix flake check validates structure, formatting, lint, types, tests, and builds without changing working files. Every repository inherits the same formatting and lint policy; no configuration is needed.

Tracking and cleanup

Builds and checks use tracked working files, including tests added by hand. Untracked files stay outside those inputs whether or not Git ignores them. Search tracked source with git grep.

A repository can keep disposable artifacts in tmp/ directories and add tmp/ to its own .gitignore. This pattern covers that directory name at any depth. Tools that write caches elsewhere may need additional patterns. Project ignore rules remain under your control; tracking determines membership.

Home commands maintain ~/.gitignore as an allowlist: * ignores new files, with exceptions for .gitignore, .gitmodules, and registered submodule directories and their parents. These exceptions follow .gitmodules when repositories are added, moved, or removed. Add personal exceptions below them, including any parent directories. Afairesi preserves personal rules and their staging while updating its structural rules.

From a project root, preview untracked files to remove, including ignored files:

git clean -ndx

Remove them with git clean -fdx. Tracked edits survive; cleanup neither restores a revision nor cleans tracked submodules. Persistent application state follows its Preservation declarations.

Design principle

Afairesi (αφαίρεση, subtraction or abstraction) favors declaring each essential fact once and deriving the rest. Git owns source membership and history; Preservation declares persistent state; Afairesi derives builds, checks, and environments. The home allowlist follows submodule registrations; project ignore rules belong to each repository's workflow.

Conventions should remove more decisions than their implementation and exceptions introduce, while preserving required behavior. The paper explains the tradeoffs.

Install

The CLI requires Git and Nix with flakes on Linux or Apple Silicon macOS. The full environment uses NixOS with Preservation.

Use this flake.nix to derive packages, checks, and hosts:

{
  inputs.afairesi.url = "github:afairesi/afairesi";
  outputs = inputs: inputs.afairesi.lib.mkFlake { inherit inputs; };
}

Install the CLI in a host's configuration.nix:

{ inputs, pkgs, ... }:
{
  environment.systemPackages = [
    inputs.afairesi.packages.${pkgs.stdenv.hostPlatform.system}.afairesi
  ];
}

Or start a shell with the CLI:

nix shell github:afairesi/afairesi

To manage hosted repositories as home submodules:

afairesi home init
afairesi home add https://github.com/<user>/<repo>.git

In an empty Git worktree, create a project and package:

afairesi repo init
afairesi repo add example python

Python and HTML builds include supporting files from the package source, excluding conventional tests and build metadata. Lean modules live beside main.lean. Nix packages may import main.nix; test_main.nix returns a check derivation. Python and Lean4 packages receive development shells.

Campaign reports are kept in $XDG_STATE_HOME/afairesi, defaulting to ~/.local/state/afairesi.
