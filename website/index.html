afairesi

Source MIT License

What: A CLI and Nix flake library for organizing Git repositories, packages, and NixOS configurations.

Why: Keep projects predictable and their builds reproducible through a shared directory structure.

Run without installing 
nix run github:afairesi/afairesi -- --help
Install on NixOS

Add afairesi to your system flake:

inputs.afairesi.url = "github:afairesi/afairesi";

With inputs in your NixOS module's scope, add:

environment.systemPackages = [
  inputs.afairesi.packages.${pkgs.stdenv.hostPlatform.system}.default
];

Apply:

sudo nixos-rebuild switch
Install on non-NixOS systems 
nix profile add github:afairesi/afairesi
Repository setup

For an existing afairesi repository, initialize your home repository, add the submodule, and enter it: 

afairesi home init
afairesi home add https://github.com/you/project.git
cd ~/github.com/you/project

Existing afairesi repositories already contain their flake. For a new project, initialize a Git repository containing only .git: 

git init project
cd project
afairesi repo init

Run afairesi repo and local Nix commands from the project's directory.

Directory structure

At repository and package level, optional prm/ directories hold permanent project files tracked by Git; optional tmp/ directories hold ignored temporary files.
