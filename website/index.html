afairesi

Source MIT License

A CLI and Nix flake library for NixOS with impermanence or preservation. Manage a Git-based home directory, repositories, packages, and system configurations.

Install on NixOS

For NixOS with impermanence or preservation, install through your existing system flake. Add the afairesi input and pass inputs through specialArgs: 

{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    afairesi.url = "github:afairesi/afairesi";
  };
  outputs = inputs@{ nixpkgs, ... }: {
    nixosConfigurations.my-host = nixpkgs.lib.nixosSystem {
      specialArgs = { inherit inputs; };
      modules = [ ./my-host/configuration.nix ];
    };
  };
}

Keep your existing nixpkgs input and NixOS settings. Adapt my-host and the module path to your configuration. In that module, include the package: 

{ inputs, pkgs, ... }:
{
  # Your existing NixOS settings go here.
  nix.settings.experimental-features = [ "nix-command" "flakes" ];
  environment.systemPackages = [
    inputs.afairesi.packages.${pkgs.stdenv.hostPlatform.system}.default
  ];
}

Apply from the directory containing your configuration's flake.nix:

sudo nixos-rebuild switch --flake .#my-host

In your existing impermanence or preservation configuration, persist ~/.git/, ~/.gitignore, ~/.gitmodules, and repository directories such as ~/github.com/ across reboots.

Other systems: home and repo

On other systems with Nix, use afairesi home and afairesi repo independently. Enable these features in ~/.config/nix/nix.conf: 

experimental-features = nix-command flakes

Run without installing:

nix run github:afairesi/afairesi -- repo --help

Or install for your user (Nix 2.30 or newer):

nix profile add github:afairesi/afairesi
Get started

To use the home-directory model, initialize your home repository and add an existing hosted repository (replace the example URL with your own): 

afairesi home init
afairesi home add https://github.com/you/repo.git

This registers the repository at ~/github.com/you/repo/. Use a destination that does not already exist.

After installing, create a flake in a new, empty Git worktree:

mkdir -p ~/github.com/you/new-repo
cd ~/github.com/you/new-repo
git init
afairesi repo init
afairesi repo add hello python
nix run .#hello

Replace you/new-repo with your repository path. Initialization generates flake.nix, flake.lock, and .gitignore; repo add creates the package files. Changes are staged; use Git to commit and push.

The generated flake uses the library as follows. mkFlake discovers packages with default.nix and hosts with configuration.nix in immediate subdirectories, and supplies inputs to their modules: 

{
  inputs.afairesi.url = "github:afairesi/afairesi";
  outputs = inputs: inputs.afairesi.lib.mkFlake { inherit inputs; };
}
