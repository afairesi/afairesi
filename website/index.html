A CLI and Nix flake library for managing your home directory, repositories, packages, and NixOS configurations.

Install on NixOS

As a library (flake.nix):

{
  inputs.afairesi.url = "github:afairesi/afairesi";
  outputs = inputs: inputs.afairesi.lib.mkFlake { inherit inputs; };
}

As a CLI (your NixOS configuration):

{ inputs, pkgs, ... }:
{
  environment.systemPackages = [
    inputs.afairesi.packages.${pkgs.stdenv.hostPlatform.system}.afairesi
  ];
}
