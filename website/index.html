afairesi

A Nix library and CLI for consistent repositories.

Library CLI Source MIT License

Define packages once. Derive builds, checks, and development environments from the repository layout, then inspect interfaces and run tests with two CLI commands.

Nix library

mkFlake discovers package directories containing default.nix and connects them to Nix builds, formatting, checks, and test environments.

Connect a repository

flake.nix

{
  inputs.afairesi.url = "github:afairesi/afairesi";
  outputs = inputs:
    inputs.afairesi.lib.mkFlake { inherit inputs; };
}

Keep each package in a directory at the repository root. Track its source and supporting files with Git so Nix includes them in builds. 

project/
├── flake.nix
├── flake.lock
└── example/
    ├── default.nix
    ├── main.py
    └── test_main.py  # Optional
example/default.nix 
{ inputs, pkgs, ... }:
inputs.afairesi.lib.mkPythonPackage {
  inherit pkgs;
  executable = true;
  meta.description = "An example Python command.";
  src = ./.;
}

Define main() in main.py for an executable. Set executable = false; for a Python or Lean library.

Package conventions

Package Builder Source
Python mkPythonPackage main.py
Lean 4 mkLean4Package main.lean
HTML mkHtmlPackage index.html
LaTeX mkLatexPackage ms.tex
Nix Any derivation default.nix

Optional test_main.py, test_main.lean, and test_main.nix files provide package checks. Python and Lean packages also get a <name>-test development shell. 

nix flake lock
nix fmt
nix flake check
nix build .#example
nix run .#example
nix develop .#example-test

Repository CLI

Install the CLI with Nix, or run it directly without installing.

nix profile add github:afairesi/afairesi
nix run github:afairesi/afairesi -- --help

afairesi inspect

Read package metadata, CLI arguments, and test identifiers as JSON. Inspection reads source without executing it. Pass a local repository path or Git URL as the optional argument; omitting it selects the current repository. 

afairesi inspect
afairesi inspect ../project

Use inspect-diff to compare interfaces in the working tree, index, or Git revisions. Pass an optional repository path and select revisions with --from and --to. Add --merge-base with both revisions to compare their common ancestor with --to. Implementation changes that leave the interface unchanged are omitted. 

afairesi inspect-diff
afairesi inspect-diff --cached
afairesi inspect-diff --from HEAD~1 --to HEAD

Python test campaigns

Choose a Python test campaign. The optional path selects one package or a whole flake; omitting it selects the current repository. Repository campaigns skip packages without Python tests.

test-coverage
Build coverage checks and print HTML report paths in the Nix store.
test-fuzz
Run Hypothesis tests named test_fuzz_*.
test-mutation
Change source expressions to check whether the tests catch them.
test-performance
Profile tests and package CLI calls with cProfile.
test-property
Run complete test suites, including Hypothesis property tests.
afairesi test-property
afairesi test-coverage example
afairesi test-fuzz example --max-examples 100
afairesi test-mutation example --max-mutations 20
afairesi test-performance example

Use -k and -m to select tests in campaigns other than coverage. Add --help to any command for its options.
