afairesi

Source MIT License

A CLI and Nix flake library for organizing your home directory and Git repositories through a consistent directory structure.

Run or install

Run without installing:

nix run github:afairesi/afairesi -- --help

Or install on non-NixOS systems:

nix profile add github:afairesi/afairesi

Or install on NixOS by adding to flake.nix:

{
  ...
  inputs.afairesi.url = "github:afairesi/afairesi";
  ...
}

With inputs passed to your module, add to configuration.nix: 

{ inputs, pkgs, ... }:
{
  ...
  environment.systemPackages = [
    ...
    inputs.afairesi.packages.${pkgs.stdenv.hostPlatform.system}.default
  ];
  ...
}

Apply the NixOS configuration:

sudo nixos-rebuild switch
